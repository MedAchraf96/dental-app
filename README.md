# Dental Appointment System

Flask application for managing dental appointments

## Features
- Patient management
- Appointment scheduling
- Dentist dashboard
- Calendar integration

## Setup
1. Create .env file (copy from .env.example)
2. Install dependencies: pip install -r requirements.txt
3. Initialize database: lask create-admin
4. Run: lask run

## Configuration
Edit .env for:
- Database settings
- Secret key
- Admin credentials
